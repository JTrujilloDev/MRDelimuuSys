# Versión 2.0: usuarios, puntos y terminales

Esta entrega parte de la rama `1.1.0` y crea esta estructura inicial:

- Delimuu principal, con cocina habilitada.
- Veleño 1, sin cocina.
- Veleño 2, sin cocina.
- Una terminal inicial por cada punto cuando no existe una previa.

Los puntos de Veleño son independientes. No comparten cuentas, cajas ni inventario. El catálogo compartido y el inventario por ubicación se documentan en `2.0-second-step.md`.

## Aplicación de base de datos

Con `DATABASE_URL` configurada, desde `apps/backend`:

```sh
npx prisma migrate deploy
npx prisma generate
```

Las migraciones conservan las tiendas, terminales, usuarios, cuentas y cajas existentes. El punto existente más antiguo se identifica como `DELIMUU_MAIN`; los usuarios actuales conservan acceso a ese punto.

## Primer administrador

Configurar temporalmente estas variables en el entorno del backend:

```text
ADMIN_NAME=Nombre del administrador
ADMIN_EMAIL=correo@ejemplo.com
ADMIN_PASSWORD=una-clave-segura-de-minimo-10-caracteres
```

Después ejecutar una sola vez:

```sh
npm run admin:bootstrap
```

El comando crea o actualiza el administrador, cifra la contraseña y le asigna acceso a todos los puntos activos. Las variables pueden retirarse después de ejecutarlo.

## Sesiones

- `SESSION_TTL_HOURS` define la duración absoluta de la sesión; el valor predeterminado es 12.
- `COOKIE_SECURE=false` es necesario mientras la instalación se sirva mediante HTTP en la red local.
- Al habilitar HTTPS, cambiar `COOKIE_SECURE=true`.
- `CORS_ORIGINS` admite una lista separada por comas para el desarrollo. En el despliegue del mismo origen mediante Nginx no es necesario habilitar orígenes adicionales.

## Reglas implementadas

- Solo un turno abierto por terminal.
- Solo un turno abierto por usuario.
- No se puede cambiar de punto con una caja abierta.
- Los usuarios desactivados pierden sus sesiones activas.
- Las cuentas, cajas y movimientos financieros se restringen al punto seleccionado.
- Veleño no puede consultar ni crear comandas de cocina.
- Los puntos y terminales con historial se desactivan; no se eliminan.
